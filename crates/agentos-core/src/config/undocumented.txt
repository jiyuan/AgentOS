# Config keys that have no doc comment yet.
#
# Roadmap item X4. The catalog is derived from the config structs, so a key
# with no `///` on its field would render a blank description — which reads as
# "this key does nothing" rather than "nobody wrote this down". The generator
# refuses to invent one, so every such key is listed here.
#
# This list is a ratchet, and it only turns one way:
#
#   - a key that is missing a doc and is NOT listed here fails the check, so a
#     new config key cannot be added without saying what it does;
#   - a key that IS listed here but has since gained a doc also fails, so the
#     list cannot go stale and shrinks as the debt is paid.
#
# Delete a line by writing the doc comment on its field. Do not add lines to
# make a check pass.
#
# The list is empty. Every config key `agent.toml` accepts has a doc comment on
# its field, and `docs/CONFIG_CATALOG.md` renders it (M7 / `CFG-001`,
# deliverable 8). It started at 102 keys.
#
# Keep it that way: adding a key without a `///` fails the check, and adding a
# line here to silence that is the one thing this file is not for.
